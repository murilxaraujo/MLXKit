# ``MLXKit``

A high-level Swift framework for machine learning on Apple silicon, built on MLX.

## Overview

MLXKit provides a streamlined interface for loading, running, and fine-tuning
machine learning models using [MLX Swift](https://github.com/ml-explore/mlx-swift).
It handles model discovery, weight loading, tokenization, and inference so you
can focus on building great experiences.
